## HARD-WON GOTCHAS (2026-09-06, sketchybar 2.24.0 + macOS 26.6.2)

1. blur_radius=0 ON PURPOSE. 2.24.0 renders blur BEYOND the bar frame ->
   "melted glass" strip under the bar (#827); bar color is opaque anyway.

2. Gap between bar and windows is AEROSPACE outer.top (=10), NOT sketchybar.

3. BASH BUG: `"$TEMP°"` (unbraced var + multibyte char) -> bash emits a lone
   0xb0 byte, sketchybar renders literal "Warning: Malformed UTF-8 string".
   ALWAYS brace: "${TEMP}°".

4. 2.24.0 rendering rework (relevant when editing items/plugins):
   - item `x_offset` REMOVED (use `background.x_offset`)
   - `background.width` not a property
   - `--add group` renamed to `--add bracket`

5. `updates=when_shown` (global default) stops polling on hidden items ->
   use `updates=on` for anything that hides (notifications items).

6. lsappinfo only sees RUNNING apps (a quit Outlook/Teams/Webex shows no
   badge). No fallback, deliberate.

7. Logs: /opt/homebrew/var/log/sketchybar/{sketchybar.err.log,sketchybar.out.log}
   `sh: /x.sh: No such file` = $PLUGIN_DIR was empty when item was created.

8. Concurrent-edit hazard: other sessions edit these files; verify LIVE state
   with `sketchybar --query item <name>` — disk != loaded sometimes.

9. Fonts: SF Pro (text/SF Symbols), sketchybar-app-font (brand glyphs),
   SF Symbols Fallback.otf (apple popup glyphs). Nerd Fonts installed for
   terminal but NOT used by sketchybar (deliberate).
