# WM: AeroSpace  (~/.config/aerospace/aerospace.toml, from ~/.config/kitchen-sink/config/aerospace)
# No status bar. Hyper+S = ONE view: a row per occupied workspace (key chip,
#   accent = focused; app icons; red badge = unread), a command grid
#   (in-palette commands; Jira/Confluence/Notes/AI/Compare/Files are
#   in-palette = false, they live in the app), and a status row (unread chips
#   · CPU · RAM · battery · clock). Typing narrows all of it: an app/window
#   title hit names itself INSIDE its workspace row (never a 2nd row); a bare
#   key ("w", "3") puts that workspace first; "/" = commands only.
#   Keys: Up/Down rows, Left/Right grid cells, Tab workspaces<->commands,
#   Esc clears query then hides, click runs a row/cell.
#   [app] switcher-width (380) / switcher-columns (3) in commands.toml.
#   Unread counts: notify/notify_poll.py --json (Dock / Webex-window badges via
#   notify/helpers/*.swift) -> NEEDS Accessibility for kitchen-sink.app.
# Kitchen sink (AppKit popup, karabiner-bound): ~/.config/kitchen-sink/kitchen_sink.swift
#   Reusable window framework: ~/.config/kitchen-sink/PopupWindow.swift (config-driven popup:
#   size/colors/fonts via PopupConfig; optional search/navigation/escape/toggle/
#   click-off handlers; rows via PopupRow protocol). Entry point in main.swift.
#   Build: swiftc -O -swift-version 5 PopupWindow.swift kitchen_sink.swift main.swift
#   -o kitchen-sink (multi-file build needs the entry point in main.swift)
#   Toggle IPC is name-scoped: socket $TMPDIR/<name>.sock, message "toggle <name>".
#   Native Swift/AppKit port (2026-09-09) of the old Tk/PIL version.
#   Daemon + Unix socket (no file polling): .sh pings $TMPDIR/kitchen-sink.sock,
#   builds the binary if the .swift source is newer, launches if not running.
#   Real transparency via NSWindow isOpaque=false + layer cornerRadius (Tk 9
#   couldn't do this — corners rendered black, see below for the old fix).
#   Build: swiftc -O -swift-version 5 kitchen_sink.swift -o kitchen-sink
#   GOTCHA: flipped NSView (isFlipped=true) mirrors NSImage.draw — use the
#     CTM-flip helper (drawImage(_:in:)) for icons, not plain draw(in:).
#   GOTCHA: NSPanel must be .nonactivatingPanel + canBecomeKey=true or the
#     popup never gets keyboard focus (and Esc/arrows won't work). With
#     nonactivating, the user's app stays frontmost — no focus stealing.
#   GOTCHA: the field editor swallows nav keys before NSTextField.keyDown —
#     use NSEvent local monitor (.keyDown) to intercept Down/Up/Tab/Return/
#     Esc/ctrl-n/p/j, pass other events through for text filtering.
#   GOTCHA: nonactivating panels don't resign key on outside click — dismiss
#     via NSEvent global monitor (.leftMouseDown outside window.frame).
#   Commands come from commands.toml ("name = shell script"). Loaded once at
#     start; missing config is non-fatal. Commands run in a persistent bash
#     child (CommandRunner, spawned at daemon start) so there's no shell
#     startup cost.
#   Native Swift/AppKit port (2026-09-09) of the old Tk/PIL version.
#   Aerospace IPC uses its socket directly (/tmp/bobko.aerospace-<user>.sock,
#   4-byte LE version handshake + length-prefixed JSON), Process fallback.
#   Tk 9 GOTCHA (2026-09-08): -transparent attr does NOT flip NSWindow.opaque,
#     so rounded corners rendered black. Fix in _make_borderless(): explicit
#     setBackgroundColor:clearColor + setOpaque:NO via objc bridge.
#     Frame render is opaque-RGB + separate alpha mask (rounded_base) so LANCZOS
#     can't bleed transparent-black into edges.
#   defaults write org.python.python ApplePersistenceIgnoreState -bool YES
#     (suppresses macOS "reopen windows?" crash-restore modal that otherwise
#     deadlocks EVERY new python-Tk launch after any python GUI crash)
# Karabiner (caps_lock -> Hyper; Hyper+S = switcher): ~/.config/kitchen-sink/config/karabiner/karabiner.json
#   brew install --cask karabiner-elements
#   import via Karabiner GUI (profile dropdown -> Import)
#   then activate the system extension (System Settings -> Privacy & Security -> Allow)
# Disabled on purpose:

# ---- Upcoming events/alerts (2026-09-08) ----
# events/events.py -- config-driven osascript queries of Calendar.app (covers Webex
# meetings synced to Work) + optional Microsoft Outlook adapter. No pip deps.
#   python3 events/events.py             # text list of upcoming events
#   python3 events/events.py --json      # machine-readable (for popups)
#   python3 events/events.py --horizon 7 # override lookahead days
# config: events/events.json -> sources[] {id, app, adapter: calendar|outlook,
#   calendars: [...], match: <optional regex tag, e.g. "webex">}
# Add an app by adding a JSON source entry; no code change.
# Requires Automation permission (host terminal -> Calendar) + a running Calendar.app.
# Gotchas: AppleScript date "1970-01-01" literal is tz-naive -> subtract (time to GMT)
#   for correct epochs; `whose`-filters and `repeat with e in events` are unreliable in
#   Calendar.app -> use bulk `property of every event` + index-zip + Python-side filtering.
#   Events crossing a DST boundary may be off by 1h (rare for upcoming alerts).

# ---- AeroSpace "workspace 10" on the external (DisplayLink) — FIXED 2026-09-29 ----
# Source rule (tree/Workspace.swift getStubWorkspace): a newly connected monitor gets
# an invisible workspace force-assigned to it; if none, AeroSpace invents the first
# unused number NOT in persistent-workspaces -> "10". Old config pinned everything to
# ['DELL','main'] = one monitor, so the other got "10" whenever the DisplayLink name
# didn't match or the Dell was main. Fix: 1-8,M,Y,W = ['^(?!built-in)','built-in','main']
# (any non-built-in screen, name-independent), 9 = ['built-in','main'].
# No config switch disables the stub, so there's also a GUARD:
#   kitchen-sink/config/aerospace/no_stray_workspaces.sh
#   runs on aerospace exec-on-workspace-change + the switcher daemon on display
#   change / wake (startStrayGuard, SENDER=display_change|system_woke). Any workspace not in M Y W 1-9 -> windows moved to a real one,
#   monitor switched to its assigned workspace, stray GC'd. Fast path 1 CLI call (~30ms).
#   Phantom monitor w/ nothing assigned: windows evacuated, stray left empty+invisible.
#   Log: log show --predicate 'senderImagePath contains "logger"' --last 1h | grep no_stray
#   Tested 2026-09-29: `aerospace workspace 10` and a window on 10 both reverted in <2s.
